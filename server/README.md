# 접수 받기 설정

홈페이지의 신청·문의를 **구글 시트에 저장**하고 **텔레그램·이메일로 알림**을 받는 설정입니다.
서버를 따로 빌릴 필요가 없고 비용도 들지 않습니다.

설정을 마치기 전까지 홈페이지의 폼은 "지금은 카톡·전화로 접수받고 있습니다" 안내와 함께
카카오톡·전화 버튼을 보여줍니다. 접수가 조용히 사라지는 일은 없습니다.

---

## 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 시트를 만듭니다. 이름은 `깐부애드 접수` 정도로.
2. 주소창에서 **시트 ID**를 복사합니다.
   `https://docs.google.com/spreadsheets/d/`**`여기가 시트 ID`**`/edit`

## 2. 텔레그램 봇 만들기 (알림용)

1. 텔레그램에서 **@BotFather** 를 찾아 `/newbot` 을 보냅니다.
2. 봇 이름과 아이디를 정하면 **토큰**을 줍니다. (`8012345678:AAE...` 형태)
3. 방금 만든 **내 봇과의 대화방을 열고 아무 말이나 한 번 보냅니다.** (이걸 해야 봇이 메시지를 보낼 수 있습니다)
4. 채팅 ID는 3단계 설정 후 `채팅ID찾기` 함수로 확인할 수 있습니다.

> 텔레그램 대신 이메일만 쓰셔도 됩니다. 그 경우 `EMAIL_TO` 만 채우세요.

## 3. 스크립트 올리기

1. [script.new](https://script.new) 로 새 Apps Script 프로젝트를 만듭니다.
2. 기본 코드를 모두 지우고 [`apps-script.gs`](apps-script.gs) 내용을 **전부 붙여넣습니다.**
3. 맨 위 `SETTINGS` 를 채웁니다.

```js
const SETTINGS = {
  SHEET_ID: '1AbC...여기에 시트 ID',
  SHEET_NAME: '접수',
  TELEGRAM_TOKEN: '8012345678:AAE...',
  TELEGRAM_CHAT_ID: '',        // 4단계에서 채웁니다
  EMAIL_TO: 'a01027770093@gmail.com'
};
```

4. 저장한 뒤 상단에서 `채팅ID찾기` 함수를 선택하고 **실행**합니다.
   - 처음 실행하면 권한 승인 창이 뜹니다. 본인 계정으로 허용해 주세요.
   - 실행 기록(보기 → 실행 로그)에 `"chat":{"id":123456789` 처럼 나옵니다. 이 숫자가 채팅 ID입니다.
5. `TELEGRAM_CHAT_ID` 에 그 숫자를 넣고 저장합니다.
6. `테스트` 함수를 실행합니다. **시트에 줄이 생기고 텔레그램으로 알림이 오면 성공입니다.**

## 4. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**
2. 유형은 **웹 앱**
3. 설정
   - 실행 주체: **나**
   - 액세스 권한: **모든 사용자** ← 이게 중요합니다. 홈페이지 방문자가 보내야 하니까요.
4. **배포**를 누르면 `https://script.google.com/macros/s/AKfy.../exec` 주소가 나옵니다. 복사합니다.
5. 그 주소를 브라우저에서 열어 `{"ok":true,...}` 가 보이면 정상입니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
> 새 배포를 또 만들면 주소가 바뀌니 주의하세요.

## 5. 홈페이지에 주소 넣기

[`js/app.js`](../js/app.js) 맨 위 `CONFIG` 의 `formEndpoint` 에 4단계 주소를 넣고 커밋·푸시합니다.

```js
const CONFIG = {
  phone: "1588-9097",
  openChatUrl: "https://open.kakao.com/o/s1om9Ovi",
  kakaoId: "gganbu0",
  formEndpoint: "https://script.google.com/macros/s/AKfy.../exec"
};
```

1~2분 뒤 사이트에 반영되면, 홈페이지에서 직접 한 건 넣어보고 시트와 텔레그램을 확인하세요.

## 접수되는 폼 (4곳)

| 종류 | 위치 | 담기는 내용 |
|---|---|---|
| 상담 문의 | 홈 하단 문의 | 고객 유형, 관심 플랫폼, 이름, 업체명, 연락처, 문의 내용 |
| 상품 신청 | 플랫폼별 상품 페이지 | 플랫폼, 상품, 수량, 예상 금액, 작업 주소, 업체명, 연락처 |
| 창업교육 문의 | 대행사 창업교육 | 이름, 연락처, 현재 상황, 궁금한 점 |
| 무료체험 신청 | 무료체험 팝업 | 받을 체험, 업체명, 연락처, 소식 수신 동의, (이어서) 체험 주소 |

접수번호는 `GA-251021-4821` 형태로 날짜가 들어갑니다. 시트와 알림, 고객 화면에 같은 번호가 보입니다.

## 시트에 쌓이는 칸

```
접수시각 | 접수번호 | 종류 | 이름 | 업체명 | 연락처 | 플랫폼 | 상품·항목 | 수량 | 금액 | 작업 주소 | 내용 | 기타 | 처리상태 | 원본
```

폼마다 받는 항목이 달라서, 자주 쓰는 항목은 칸을 따로 두고 나머지는 `기타` 에 모읍니다.
`원본` 칸에는 받은 내용 전체가 그대로 들어가므로 빠지는 정보는 없습니다.

칸을 바꾸고 싶으면 `apps-script.gs` 의 `COLUMNS` 만 고치면 첫 줄도 따라서 바뀝니다.
이미 쓰던 탭은 `접수_이전1` 로 이름만 바뀌어 남고, 새 칸 구성으로 `접수` 탭이 새로 만들어집니다.

## 자주 생기는 문제

- **알림이 안 와요** → 봇과의 대화방에서 내가 먼저 말을 걸었는지 확인하세요. 안 하면 봇이 메시지를 못 보냅니다.
- **시트에 안 쌓여요** → `SHEET_ID` 가 맞는지, 배포 시 "실행 주체: 나"로 했는지 확인하세요.
- **홈페이지에서 "전송되지 않았습니다"가 떠요** → 배포 설정에서 액세스 권한이 **모든 사용자**인지 확인하세요.
  수정했다면 **새 버전으로 다시 배포**해야 반영됩니다.
- **코드를 고쳤는데 그대로예요** → 새 버전 배포를 안 한 경우입니다.

## 개인정보 유의사항

이 시트에는 고객의 이름·연락처가 쌓입니다.

- 시트 공유 범위를 **본인만** 으로 유지하세요.
- 홈페이지 동의 문구에 **"상담 종료 후 1년 보관"** 이라고 적혀 있습니다. 오래된 줄은 주기적으로 지워 주세요.
- 개인정보처리방침 페이지와 사업자등록번호 표기는 아직 홈페이지에 없습니다. 별도로 준비가 필요합니다.

## 배포 후 반영이 늦을 때

GitHub Pages 는 css·js 를 10분간 캐시합니다. 바로 반영하려면 index.html 의
`css/style.css?v=...`, `js/app.js?v=...` 숫자를 올려서 함께 커밋하세요.
