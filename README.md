# 깐부애드 GGANBU AD

개발사 직속 마케팅 총판 **깐부애드** 공식 홈페이지 (정적 사이트).

## 구성

```
index.html      메인 페이지 (원페이지 구성)
css/style.css   스타일
js/app.js       상품 데이터 · 인터랙션
images/         로고 · 배너 · 플랫폼 이미지
```

## 로컬에서 보기

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000 접속.

## 배포

GitHub Pages(main 브랜치 루트)로 서비스됩니다.
